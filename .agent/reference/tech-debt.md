## ⚠️ 현재 문제점 (High Priority)

### 1. 초기화 로직 분산 🔴

**문제**: `drive.service.js`, `storage.manager.js`, `auth.service.js`에 초기화 로직이 분산됨. A를 수정하면 B, C가 파손되는 연쇄 부작용 발생.

**해결 계획**: Phase 기반 플러그인 시스템으로 리팩토링 → [initialization.md](./initialization.md)

**우선순위**: P0

---

### 2. 중복 API 호출 🟡

**문제**: 루트 폴더(`Ghostwriter_Data`)를 여러 서비스가 각각 독립적으로 검색.

**해결 계획**: Phase 시스템에서 context를 통해 결과 공유. 한 번 찾은 폴더 ID를 재사용.

**우선순위**: P1

---

### 3. 에러 핸들링 미흡 🟡

**문제**: 전역 try-catch만 있고 단계별 에러 처리 없음.

**해결 계획**: Phase별 에러 핸들링. 단계별 성공/실패 추적.

**우선순위**: P1

---

## 🔒 보안 관련

**문제**: `status.json`에 API 키가 평문으로 저장됨.

**해결 계획**: 브라우저 로컬 스토리지 사용 (단기), 암호화하여 Drive 저장 (장기)

**우선순위**: P2
