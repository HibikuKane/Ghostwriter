# Ghostwriter 문서

이 디렉토리는 Ghostwriter 프로젝트의 설계 문서를 담고 있습니다.

## 📚 문서 목록

### 필수 문서

1. **[ARCHITECTURE.md](./ARCHITECTURE.md)** ⭐
   - 프로젝트 전반적인 아키텍처
   - 설계 원칙 및 코딩 컨벤션
   - 새 세션 시작 시 **반드시** 먼저 읽어야 함

2. **[initialization.md](./initialization.md)**
   - 로그인 후 초기화 프로세스 상세 설계
   - Phase 기반 확장 시스템
   - 현재 문제점 및 개선 방향

## 🎯 새 세션 시작 시 가이드

새로운 대화 세션에서 개발을 시작할 때:

1. ✅ `ARCHITECTURE.md` 먼저 읽기
2. ✅ 작업 영역 관련 문서 확인 (예: `initialization.md`)
3. ✅ 설계 원칙을 따르는지 확인하며 작업
4. ✅ 변경 사항이 있으면 문서도 함께 업데이트

## 📝 문서 작성 가이드

새 설계 문서를 추가할 때:

- 명확한 제목과 목적 명시
- 장단점 분석
- 마이그레이션 전략 (기존 코드가 있는 경우)
- 업데이트 히스토리 추가
