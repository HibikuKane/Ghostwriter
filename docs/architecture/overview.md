# 프로젝트 개요

> **목적**: Ghostwriter가 무엇이고, 왜 만들어졌는지 설명합니다.

**마지막 업데이트**: 2026-02-15

---

## 📋 Ghostwriter란?

**Ghostwriter**는 Google Drive 기반의 서버리스 AI 롤플레이 및 소설 작성 클라이언트입니다.

---

## 🎯 핵심 특징

### 1. **서버리스 (Serverless)**

모든 데이터는 사용자의 Google Drive에 저장됩니다.

**장점**:
- ✅ 서버 비용 $0
- ✅ 사용자 데이터 완전 소유
- ✅ 서버 다운타임 없음

**구현**:
- Google Drive API 사용
- `drive.file` 스코프 (앱이 만든 파일만 접근)

### 2. **오픈소스 (Open Source)**

투명성과 신뢰를 위해 소스코드 공개

**목적**:
- ✅ 사용자가 직접 코드 검증 가능
- ✅ 드라이브 조작 투명성 확보
- ✅ 커뮤니티 기여 가능

### 3. **멀티 플랫폼 (Multi-Platform)**

웹 브라우저만 있으면 어디서든 사용 가능

**지원 환경**:
- Desktop (Windows, Mac, Linux)
- Mobile (브라우저)
- Tablet

### 4. **동기화 (Synchronization)**

Google Drive를 통해 모든 기기에서 설정 및 데이터 동기화

**동기화 항목**:
- 사용자 설정 (API 키, LLM 모델 등)
- 캐릭터 정의
- 채팅 세션 히스토리
- 프리셋

## 🎨 주요 기능

### 현재 구현된 기능 🟢

- **Google 인증**: OAuth 2.0 로그인
- **LLM 통합**: Google Gemini 지원
- **채팅**: 캐릭터와 대화
- **설정 관리**: Drive에 저장/로드
- **세션 저장**: 대화 내역 보존

### 개발 중 🟡

- **초기화 로직 리팩토링**: Phase 기반 시스템

### 계획 중 ⚪

- 캐릭터 관리 UI
- 다중 LLM 프로바이더 (OpenAI, Claude)
- 고급 프리셋 시스템
- 오프라인 모드

## 🎯 타겟 사용자

1. **AI 롤플레이 애호가**
   - 캐릭터와의 대화를 즐기는 사용자
   - 데이터 소유권을 중요하게 생각

2. **소설 작가**
   - AI를 작성 보조 도구로 활용
   - 클라우드 동기화 필요

3. **개발자**
   - 오픈소스 프로젝트에 관심
   - 커스터마이징 원함

## 🔒 보안 & 프라이버시

### 데이터 저장
- ✅ 모든 데이터는 **사용자의 Drive**에만 저장
- ✅ 서버를 거치지 않음
- ✅ 개발자도 사용자 데이터에 접근 불가

### OAuth 스코프
- ✅ `drive.file` 스코프만 사용 (앱이 생성한 파일만 접근)
- ✅ 사용자의 다른 Drive 파일에는 접근 불가

### API 키
- 🟡 현재: 사용자가 직접 입력, Drive에 평문 저장
- 🔜 향후: 암호화하여 저장 예정
