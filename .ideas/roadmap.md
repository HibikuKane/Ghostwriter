# 개발 로드맵

Ghostwriter의 현재 우선순위 기능들을 6개 Phase로 나누어 체계적으로 개발합니다.

> **참고**: 이 로드맵은 현재 계획한 기능들의 개발 순서를 보여줍니다.  
> 실제 개발 과정에서 새로운 기능이 추가되거나, 우선순위가 조정될 수 있습니다.  
> **최종 목표는 완성도 높은 AI 대화 플랫폼**이며, 이 Phase들은 그 과정의 중간 단계입니다.

## 🛠️ Phase 1 → 2 Bridge: 인프라 정비 스프린트

**목표**: Phase 1 완료 후, 대규모 기능 추가 전 기반 정비

### 테스트 자동화 기반
- ✅ 서비스 레이어 단위 테스트 (Vitest + storageManager 모킹, 54개 케이스)
- ✅ E2E 스모크 테스트 — Playwright 로그인 화면 스모크 테스트 (PR #20)
- 상세: [testing-strategy.md](./testing-strategy.md)

### GitHub Pages 배포 ✅
- ✅ Client ID 환경 분리 (`secrets.js` → `config.js`)
- ✅ Google Cloud Console 도메인 등록
- ✅ OAuth 프로덕션 게시 + 브랜딩 인증 완료
- 상세: [github-pages-deployment.md](./github-pages-deployment.md)

### 전체 플로우 하드닝
- ✅ 1일차: 로그아웃 클리어, boot.js 에러처리, LLM 에러 세분화
- ✅ UX Quick Fix: Privacy 센터링, Debug 줄바꿈, DevTools 자동스크롤
- ✅ 2일차: 토큰 만료 자동 갱신, 에러 메시지 UX 통일 (alert→인앱 토스트)
- ✅ 3일차: 네트워크 그레이스풀 디그레이드 + StorageManager 초기화 복구
- 상세: [ux-improvements.md](./ux-improvements.md), [flow-hardening.md](./flow-hardening.md)

**예상 기간**: ✅ 완료

## ✨ Phase 1.5: 채팅 UX 보완 ✅ 완료

### 완료 기능
- ✅ **응답 재생성 (리롤)**
  - AI 응답이 마음에 안 들 때 다시 생성

- ✅ **마크다운 렌더링**

- ✅ **로컬 캐시 레이어** (→ `.ideas/local-cache-layer.md`)
  - SessionStorage 기반 2-Tier 캐시
  - Drive 데이터 로드 속도 대폭 개선
  - 서버리스 철학과 완벽 호환
- ✅ **모바일 반응형 레이아웃 개선**
  - 폰 좌우폭 가독성 불량 해소
  - 미디어 쿼리 기반 전체 UI 재검토
