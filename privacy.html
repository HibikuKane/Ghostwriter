1. 개요

Ghostwriter(이하 "본 서비스")는 Google Drive 기반의 서버리스 AI 대화 클라이언트입니다. 본 서비스는 별도의 백엔드 서버를 운영하지 않으며, 모든 사용자 데이터는 사용자 본인의 Google Drive에만 저장됩니다.

핵심 원칙: 개발자는 사용자의 데이터에 접근할 수 없습니다. 모든 데이터는 사용자의 Google Drive에만 존재합니다.

2. 수집하는 정보

  • Google 계정 이메일 — 로그인 상태 표시 목적으로만 사용
  • Google Drive 파일 접근 — drive.file 스코프만 사용하여, 본 서비스가 생성한 파일에만 접근

본 서비스는 사용자의 다른 Drive 파일, 연락처, 위치 정보 등 추가적인 개인정보를 수집하지 않습니다.

3. 정보의 사용 목적

  • 사용자의 캐릭터, 대화 세션, 설정 등을 사용자의 Google Drive에 저장 및 불러오기
  • 여러 기기에서 데이터 동기화

4. 제3자 제공

본 서비스는 사용자 데이터를 제3자에게 제공하지 않습니다. 서버가 없으므로 데이터가 외부로 전송되지 않습니다.

단, 사용자가 설정한 LLM API(Google Gemini, OpenAI 등)에는 대화 내용이 전송됩니다. 이는 AI 응답을 받기 위해 필수적이며, 해당 서비스의 개인정보처리방침이 적용됩니다.

5. 데이터 보관 및 삭제

모든 데이터는 사용자의 Google Drive에 저장되므로, 사용자가 직접 삭제할 수 있습니다. 본 서비스 측에서는 어떠한 데이터도 보관하지 않습니다.

6. 쿠키 및 로컬 저장소

본 서비스는 브라우저의 localStorage를 사용하여 일부 설정(선택된 LLM 프로바이더, 모델명 등)을 저장합니다. 이는 사용자의 편의를 위한 것이며 외부로 전송되지 않습니다.

1. Overview

Ghostwriter ("the Service") is a serverless AI conversation client built on Google Drive. The Service does not operate any backend servers. All user data is stored exclusively in the user's own Google Drive.

Core Principle: The developer cannot access your data. All data exists only in your Google Drive.

2. Information We Collect

  • Google account email — Used solely to display login status
  • Google Drive file access — Uses only the drive.file scope, accessing only files created by this Service

The Service does not collect any additional personal information such as other Drive files, contacts, or location data.

3. How We Use Information

  • Save and load characters, chat sessions, and settings to/from your Google Drive
  • Sync data across multiple devices

4. Third-Party Sharing

The Service does not share user data with third parties. Since there is no server, data is never transmitted externally.

However, conversation content is sent to the LLM API configured by the user (e.g., Google Gemini, OpenAI). This is necessary to generate AI responses, and the respective service's privacy policy applies.

5. Data Retention and Deletion

All data is stored in your Google Drive and can be deleted by you at any time. The Service does not retain any data on its side.

6. Cookies and Local Storage

The Service uses browser localStorage to store some preferences (selected LLM provider, model name, etc.). This data is stored locally for convenience and is never transmitted externally.

1. 概要

Ghostwriter（以下「本サービス」）は、Google Driveベースのサーバーレス型AI対話クライアントです。本サービスはバックエンドサーバーを運用しておらず、すべてのユーザーデータはユーザー自身のGoogle Driveにのみ保存されます。

基本原則：開発者はユーザーのデータにアクセスできません。すべてのデータはユーザーのGoogle Driveにのみ存在します。

2. 収集する情報

  • Googleアカウントのメールアドレス — ログイン状態を表示する目的でのみ使用
  • Google Driveファイルアクセス — drive.fileスコープのみを使用し、本サービスが作成したファイルにのみアクセス

本サービスは、他のDriveファイル、連絡先、位置情報などの追加的な個人情報を収集しません。

3. 情報の利用目的

  • キャラクター、チャットセッション、設定などをユーザーのGoogle Driveに保存・読み込み
  • 複数デバイス間でのデータ同期

4. 第三者への提供

本サービスはユーザーデータを第三者に提供しません。サーバーが存在しないため、データが外部に送信されることはありません。

ただし、ユーザーが設定したLLM API（Google Gemini、OpenAIなど）には会話内容が送信されます。これはAI応答を取得するために必要であり、各サービスのプライバシーポリシーが適用されます。

5. データの保管と削除

すべてのデータはユーザーのGoogle Driveに保存されているため、ユーザーが直接削除できます。本サービス側ではいかなるデータも保持しません。

6. Cookieとローカルストレージ

本サービスはブラウザのlocalStorageを使用して、一部の設定（選択したLLMプロバイダー、モデル名など）を保存します。これはユーザーの利便性のためであり、外部に送信されることはありません。
